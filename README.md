# GIMS-12 — ICU 痛风患者 24 小时死亡风险评分

**GIMS-12**（Gout ICU Mortality Score, 12 variables）是一个床旁可算的评分，用于估算
ICU 痛风患者**入 ICU 24 小时之后**院内死亡的概率。

- 推导：MIMIC-IV，n = 2,853，事件 244（8.6%）
- 外部验证：eICU-CRD，n = 962，事件 61（6.3%）
- 内部 AUROC **0.771**（95% CI 0.740–0.801）；外部 **0.720**（0.650–0.787）

在线计算器：<https://gout-mace-calculator.streamlit.app>
（仓库名沿用旧模型名，应用内容已替换为 GIMS-12）

> **一句话结论**：只输入 12 个床旁即可获得的变量，即可在时间可定位的终点上
> 获得可跨库迁移的判别力；`verify_gims12.py` 一条命令核对全部发布件的一致性。

---

## 1. 为什么换终点

早期版本预测的是基于住院诊断编码的复合心血管终点（MACE）。该终点存在结构性缺陷：
诊断编码**没有时间戳**，无法区分事件发生在本就存在的入院原因之中，还是发生在 24 小时
预测窗之后，因此预测窗与结局窗重叠。修正特征时间窗后，该终点外部 AUROC 仅 0.656，
低于 0.70 的常规可用下限。

本版改用**入 ICU 24 小时之后的院内死亡**：MIMIC-IV 的 `deathtime` 精确到秒，
eICU-CRD 的 `hospitaldischargeoffset` 精确到分钟，事件时点可精确定位，窗口重叠问题
彻底消除。同一套变量、同一交叉验证配置下：

| 终点 | 训练事件率 | 内部 AUROC | 外部 AUROC |
|---|---|---|---|
| 24 小时后院内死亡 | 8.6% | 0.811 | **0.746** |
| 编码 MACE（原始率） | 38.1% | 0.742 | 0.655 |
| 编码 MACE（事件率匹配至 8.6%） | 8.5% | 0.670 | 0.594 |

（上表为 47 变量 XGBoost 全模型结果，用于说明终点选择的影响；事件率匹配后编码终点
反而更差，可排除“差异只是事件率不同”这一替代解释。）

## 3. 模型

`lp = 0.95324587 + Σ βᵢ·xᵢ`，`p = 1/(1 + e^(−lp))`

| 变量 | β | 变量 | β |
|---|---|---|---|
| 年龄（岁） | +0.028789 | 尿素氮（mg/dL） | +0.019790 |
| GCS 总分 | −0.086416 | 肌酐（mg/dL） | −0.091710 |
| 平均收缩压（mmHg） | −0.010406 | 血红蛋白（g/dL） | −0.067602 |
| 平均呼吸频率（/min） | +0.143920 | 血小板（×10⁹/L） | −0.001538 |
| 平均 SpO₂（%） | −0.010188 | 白细胞（×10⁹/L） | +0.015027 |
| 血钙（mg/dL） | −0.034412 | 血氯（mmol/L） | −0.045364 |

拟合：L2 正则 logistic 回归，`C = 0.1`，**不加类别权重**（保证概率已校准到真实患病率）。
变量集由 47 变量 XGBoost 模型的 SHAP 前 12 位生理/化验变量预先指定后重新拟合。

### 性能

| 指标 | 推导（5×5 CV） | 外部（eICU-CRD） |
|---|---|---|
| AUROC（95% CI） | 0.771（0.740–0.801） | 0.720（0.650–0.787） |
| Brier | 0.0707 | 0.0645 |
| 校准斜率 | 1.000 | 0.497 |
| 校准截距 | −0.002 | −1.461 |
| HL 检验 P | 0.588 | <0.001 |

**推导集校准优秀，外部集校准失败**——外部使用时必须重校准：

```
lp' = 0.4973 × lp − 1.461
```

重校准后外部 Brier 0.0577（技巧分 +0.028）。判别力不受单调变换影响。

### 风险分层（推导队列实测）

| 层 | 预测范围 | n | 事件 | 实测率 |
|---|---|---|---|---|
| Q1 | 0–3.2% | 714 | 7 | 0.98% |
| Q2 | 3.2–5.8% | 713 | 30 | 4.21% |

## 4. 使用

**离线**：双击 `gims12_calculator.html`，无需联网、无需安装。

**在线**：
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

**校验发布件**：
```bash
python verify_gims12.py
```

`verify_gims12.py` 检查四类一致性：Python 模块与 JSON 的系数是否逐位一致、
预测值与 β 直接计算是否一致、HTML 内嵌 JS 系数是否与 Python 一致、
列线图分值表方向是否与 β 符号一致。任何一项不一致即返回非零退出码。

## 5. 局限

1. 外部仅 61 例事件，AUROC 置信区间宽（0.650–0.787）。
2. eICU 用别嘌醇处方代理痛风，队列身份与推导集不完全等价。
3. 推导队列排除既往心肌梗死/卒中/心衰，模型在最高危人群中未经验证。
4. 线性模型外推无界；界面在输入超出推导队列 1–99 百分位时给出警告。
5. 变量集依据同一数据的 SHAP 排名确定，交叉验证未计入该筛选步骤，报告性能可能略微乐观。

完整说明见 `gims12_model_card.md`。
